How the circle of fifths works

Moving clockwise around the circle moves up by perfect fifths. Each neighboring major key differs by one sharp or flat. The inner ring shows the relative minor key that shares the same key signature.

Using the circle for chord progressions

Choose a key and use the suggested diatonic chords as a starting point. Progressions such as I–IV–V and ii7–V7–Imaj7 are common because they create clear harmonic movement within the selected key.

Circle of fifths FAQ

What is a relative minor?

A relative minor uses the same notes and key signature as its relative major, but centers the music around a different tonic.

Can I use the circle for songwriting?

Yes. It is especially useful for finding related keys, diatonic chords and possible modulation paths.
